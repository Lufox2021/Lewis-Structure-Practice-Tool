# Lewis Structure Practice Tool

Lewis structure practice for chemistry students, with a live 3D ball-and-stick view of the student's own drawing.

## Usage

Open `index.html` in a web browser — it is a single self-contained page.
To host it with GitHub Pages, enable Pages for this repo (Settings → Pages → deploy from the `main` branch, root folder).

## Versions

- `index.html`: the original version.
- `Lewis Structure Practice CCCC V11062026.html` (November 6, 2026): adds My own formula mode, drawing and erasing tools in the resonance boxes, and the current resonance rules. Students draw the energetically equivalent forms; higher-energy forms are shown in the feedback. Every second-row atom must keep an octet, with acrolein's charge-separated form drawn as a labeled exception.
